# CampusHire - College Placement Management System (Frontend)
React + Vite frontend with sample data. No backend or database.

## Run
1. Install Node.js 18+ from nodejs.org
2. Open this folder in VS Code, then open the terminal (Ctrl+`)
3. `npm install`
4. `npm run dev`
5. Open http://localhost:5173

Demo: use any email/password on Log in. Pick "Student" or "Placement admin".
